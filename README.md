# hateb-tycoon

はてなブックマークの人気/新着エントリーを取得して一覧表示し、ブラックリスト・ホワイトリスト・強制ブロックの3つのフィルタで不要な記事やコメントを非表示にするクライアントサイドのみの静的Webアプリです。サーバーやビルド工程は不要で、`index.html` を静的ホスティング(GitHub Pagesなど)に置くだけで動作します。

## 機能

- 一覧表示: `https://b.hatena.ne.jp/hotentry/{category}.json` をJSONPで取得し、カテゴリタブ(総合/一般/世の中/政治と経済/暮らし/学び/テクノロジー/おもしろ/エンタメ/アニメとゲーム/本)ごとに人気エントリーを表示します。
- コメント表示: 一覧の「ブックマークコメントを見る」から個別記事に遷移すると、`https://b.hatena.ne.jp/entry/jsonlite/?url=...` をJSONPで取得し、そのページをブックマークした各ユーザーのコメント・タグ・日時を表示します。
- フィルタ機能: 右上の「フィルタ設定」から、以下3種類のルールを追加・削除できます。ルールは `localStorage` に保存され、ブラウザを閉じても保持されます。
  - `blacklist`(ブラックリスト): 該当したら非表示。ただし `whitelist` に該当すれば例外的に表示。
  - `whitelist`(ホワイトリスト): `blacklist` の例外として表示を維持する。
  - `forceBlock`(強制ブロック): 該当したら `whitelist` の設定に関係なく必ず非表示。
- 各ルールは「タイトル」「ドメイン」「はてなユーザー」「ブックマークコメント」のいずれかを対象に、部分一致(大文字小文字を区別しない)で判定します。

## 判定ロジック(優先順位)

```
1. forceBlock に一致する -> 非表示(確定)
2. blacklist に一致する
     -> whitelist にも一致する -> 表示
     -> whitelist に一致しない -> 非表示
3. どちらにも一致しない -> 表示
```

## 使い方

1. リポジトリをクローンし、`index.html` を静的ファイルとして配信します(例: `npx serve .` や GitHub Pages)。`file://` で直接開いても動作しますが、ブラウザによっては `<script>` 動的挿入(JSONP)が制限される場合があるため、ローカルサーバー経由を推奨します。
2. 画面上部のカテゴリタブで表示する分野を切り替えます。
3. 記事カードの「ブックマークコメントを見る」をクリックすると、その記事にブックマークしたユーザーのコメント一覧に遷移します。
4. 右上の「フィルタ設定」からルールを追加すると、一覧・コメントの両方に即座に反映されます(再読み込み/再遷移で反映)。

## 技術的な注意点

- はてなブックマークの公開JSON APIは、環境によってはブラウザからの `fetch()` に対して CORS ヘッダーを返さないことがあるため、本アプリでは `<script>` タグ挿入による JSONP 方式でデータを取得しています。エンドポイント側が `callback` パラメータに対応していない場合や仕様変更があった場合は、取得エラーとして画面にメッセージが表示されます。
- カテゴリのAPIパス(`general` / `social` / `economics` / `life` / `knowledge` / `it` / `fun` / `entertainment` / `game` / `book`)は、はてなブックマークの公開カテゴリ構成に基づいています。実際のレスポンス項目名に変更があった場合は `js/hatena-api.js` の `normalizeHotEntry` / `normalizeEntryInfo` を調整してください。
- 完全なはてなブックマークUIの再現は行っておらず、記事一覧・コメント一覧の表示に必要最低限のリンク(元記事リンク・はてなブックマークページへのリンク・ユーザーページへのリンク)のみを組み込んでいます。
